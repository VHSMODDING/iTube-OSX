# iTube pour Mac OS X Snow Leopard

Application native Intel x86_64 pour rechercher et télécharger des fichiers audio sur Mac OS X 10.6 à 10.9.

## Installation

1. Téléchargez `iTube-Snow-Leopard.zip`.
2. Double-cliquez sur l’archive pour obtenir `iTube_legacy.app`.
3. Déplacez l’application dans le dossier Applications puis ouvrez-la.
4. Choisissez le dossier dans lequel enregistrer vos téléchargements.

## Compatibilité

- Mac OS X 10.6 Snow Leopard à 10.9 Mavericks
- Mac Intel 64 bits (Core 2 Duo ou plus récent)
- Connexion Internet requise

Ce dépôt contient uniquement l’application compilée et sa documentation de distribution.
